SyllabesToon - Linux Xubuntu x64

1. Copier SyllabesToon-Linux.zip sur le PC Linux.
2. Extraire le dossier SyllabesToon-Linux dans Documents.
3. Ouvrir un terminal dans ce dossier extrait.
4. Lancer cette commande :

   bash installer-raccourci.sh

5. Double-cliquer ensuite sur SyllabesToon sur le bureau.
6. Conserver le terminal du jeu ouvert pendant l'utilisation.

Si Xubuntu demande une autorisation, accepter de faire confiance
au lanceur ou de le rendre executable.

Pour arreter : fermer le terminal du jeu ou appuyer sur Ctrl+C.
Fermer seulement le navigateur n'arrete pas le serveur.

Jeu : http://localhost:8000/index.html
Espace enseignant : http://localhost:8000/teacher-manager.html
Code enseignant temporaire : 1234

Les exports de configuration et de voix sont transferes separement,
puis importes dans l'espace enseignant. Ils ne sont pas dans ce ZIP.

Garder le dossier de l'application a son emplacement apres installation.
Si vous le deplacez, relancer bash installer-raccourci.sh.
Node, Python et Go ne sont pas necessaires sur ce PC Linux.
