SyllabesToon - version enseignante

1. Dezipper le dossier SyllabesToon.
2. Double-cliquer sur Lancer SyllabesToon.bat.
3. Ne pas fermer la fenetre noire pendant l'utilisation.

Jeu :
http://localhost:8000/index.html

Espace enseignant :
http://localhost:8000/teacher-manager.html

Code enseignant temporaire :
1234

Pour arreter SyllabesToon :
fermer la fenetre noire.
